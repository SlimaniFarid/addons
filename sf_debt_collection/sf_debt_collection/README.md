# Credit & Debt Collection

Recover what you are owed, politely and systematically.

## Features

- Partner credit limits with automatic usage tracking
- Collection cases per customer with collector and priority
- Overdue invoice lines pulled from real accounting data
- Automatic aging: total due and total overdue
- Dunning plans with escalation levels and days-after-due
- Dunning runs with draft → sent → done workflow
- Payment promises with follow-up dates
- Collection actions log (calls, emails, letters, meetings)
- Days overdue and next promise date computed automatically
- Per-collector workload dashboards

## Installation

Install the module from Apps. Open **Accounting > Collections**.

## Usage

1. Create a collection case for a customer (or open it from a partner).
2. Press **Refresh Invoices** to pull overdue invoices from accounting.
3. Log collection actions and record payment promises.
4. Press **Create Dunning** to generate the next dunning level.
5. Work the case to resolution; track everything in the chatter.
