WhatsApp Business API

Send WhatsApp messages from Odoo Community via Meta Cloud API.

Official WhatsApp integration is only available in Odoo Enterprise. This module brings full WhatsApp Business Cloud API support to Odoo Community Edition.

Key Features

  • Cloud API Integration — Direct connection to Meta WhatsApp Business Cloud API (no on-premise container)
  • Template Management — Fetch and manage approved templates from Meta
  • Multi-Account — Support multiple WhatsApp Business accounts
  • Automated Workflows — Send on order confirmation, invoice creation, delivery update, payment reminder
  • Message Log — Full history with status tracking (sent, delivered, read, failed)
  • Variable Substitution — Dynamic template rendering with record data
  • Webhook Ready — Configure webhook URL for incoming messages and status callbacks

Supported Automations

  • Sale Order Confirmation → Send order details template
  • Invoice Posted → Send invoice with payment link
  • Delivery Validated → Send tracking info
  • Payment Overdue → Send reminder
  • Custom triggers via server actions or Studio

Setup

  1. Create a Meta Developer App and WhatsApp Business Account
  2. Get Access Token and Phone Number ID from Meta Developer Console
  3. Create WhatsApp Account record in Odoo with credentials
  4. Click "Test Connection" then "Fetch Templates"
  5. Configure automated messages via Server Actions or Studio

Requirements

Meta WhatsApp Business Account with approved templates. Internet access for API calls.

Compatibility

Odoo 18.0 and 19.0 Community & Enterprise. Works alongside native WhatsApp module on Enterprise.
