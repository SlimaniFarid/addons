# Resource Capacity Planning

Balance your team's workload across projects.

## Features

- Resource records: people, machines or spaces with daily capacity
- Allocations linked to project tasks with start/end dates
- Capacity vs allocation: utilization percentage computed live
- Overload warnings when a resource exceeds capacity
- Filters by type, team and overload status
- Per-resource and per-project dashboards
- Works with native project and task modules

## Installation

Install the module from Apps. Open **Project > Resource Planning**.

## Usage

1. Create your resources (people, machines) with daily capacity.
2. Add allocations on project tasks with hours and dates.
3. Watch utilization and overload indicators.
4. Rebalance workload to avoid overloads.
