Supplier Scorecard &amp; Quality
==============================

Evaluate and rank suppliers with clear scorecards.

Features
--------
* Periodic scorecards per supplier
* On-time delivery and defect rate KPIs
* Quality and compliance scoring
* Weighted overall score and rating
* Quality issues with resolution tracking

Requirements
------------
* Odoo 18.0 / 19.0 with Purchasing (purchase) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "Supplier Scorecard &amp; Quality".

Usage
-----
1. Go to *Purchasing &gt; Supplier Scorecard &gt; Scorecards*.
2. Create a scorecard for a supplier, enter KPIs and weights.
3. The overall score and rating are computed automatically.
4. Log quality issues under *Quality Issues*.
