First Article Inspection (FAI)
===============================

Complete FAI management per AS9102/AS9145 standards.

Features
--------
* FAI report generation (Form 1, 2, 3 per AS9102)
* Balloon drawing integration
* Characteristic accountability (100% verification)
* Non-conformance tracking with disposition
* FAI approval workflow (supplier/customer)
* Partial FAI and delta FAI support
* Export to PDF/Excel for customer submission

Requirements
------------
* Odoo 18.0 / 19.0 with Quality (quality) and Manufacturing (mrp) modules.

Installation
------------
* Copy the module folder into your addons path.
* Install "First Article Inspection (FAI)".

Usage
-----
1. Create an FAI report under *Quality > First Article Inspection > FAI Reports*.
2. Add characteristics with specifications and tolerances.
3. Record measured values and results.
4. Log non-conformances for failed characteristics.
5. Submit for approval workflow.
