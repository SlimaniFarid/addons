Multi-Company Consolidation
===========================

Consolidate accounting data across several companies.

Features
--------
* Consolidation groups with multiple companies
* Period-based consolidation runs
* Account-level entries per company
* Generate lines from posted account moves
* Consolidated totals per account

Requirements
------------
* Odoo 18.0 / 19.0 with Accounting (account) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "Multi-Company Consolidation".

Usage
-----
1. Create a group under *Accounting &gt; Consolidation &gt; Groups*.
2. Add the companies to consolidate.
3. Create a period and click *Generate from Moves* to pull posted moves.
4. Review the lines and mark the period *Done*.
