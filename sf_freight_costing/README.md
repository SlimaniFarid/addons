Freight &amp; Carrier Costing
==============================

Estimate and track freight costs per carrier and per picking.

Features
--------
* Carrier registry with cost formulas
* Cost methods: fixed, per kg, per m3, by value
* Minimum charge handling
* Automatic cost estimation on pickings
* Actual cost capture at validation

Requirements
------------
* Odoo 18.0 / 19.0 with Inventory (stock) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "Freight &amp; Carrier Costing".

Usage
-----
1. Create carriers under *Inventory &gt; Freight &amp; Costing &gt; Carriers*.
2. On a picking, select the carrier; weight, volume and estimated freight
   are computed automatically.
3. Log the actual cost under *Freight Costs* and mark it *Actual*.
