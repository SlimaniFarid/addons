Warehouse Wave Picking
======================

Group pickings into waves and release them efficiently.

Features
--------
* Waves grouping pickings by warehouse and picking type
* Automatic wave creation from a selection of pickings
* Release waves in one click
* Validate all pickings of a wave together
* Progress tracking per wave

Requirements
------------
* Odoo 18.0 / 19.0 with Inventory (stock) and stock_picking_batch modules.

Installation
------------
* Copy the module folder into your addons path.
* Install "Warehouse Wave Picking".

Usage
-----
1. Go to *Inventory &gt; Wave Picking &gt; Waves*.
2. Create a wave, then add pickings to it.
3. Click *Release* to assign the pickings.
4. Click *Validate* to complete all pickings in the wave.
