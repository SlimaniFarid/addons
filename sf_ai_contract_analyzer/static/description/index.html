User Manual

Step-by-step guide

Everything you need to get started.

1
Install the module

Copy sf_ai_contract_analyzer to your addons path, restart Odoo, then go to Apps and click Install.

2
Assign user access

Go to Settings → Users, open a user and add the AI Contract Analyzer & Obligations / User or / Manager group under the extra rights.

3
Open the application

Find AI Contract Analyzer in your Odoo main menu. Everything is organised under this single entry point.

4
Create your first record

Click New on the Contract Document list view. Fill in the required fields and save. Chatter and activities are available on every record.

5
Follow the status workflow

Use the header buttons to move records through their lifecycle. The status bar always shows the current stage.
