Project Margin &amp; Budget Control
==================================

Track project budgets, costs and margins live.

Features
--------
* Revenue and cost budgets per project
* Budget items by category
* Automatic margin and margin percentage
* Threshold warnings on margin drop
* Linked to native project records

Requirements
------------
* Odoo 18.0 / 19.0 with Project (project) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "Project Margin &amp; Budget Control".

Usage
-----
1. Open any project and go to the *Margin &amp; Budget* tab.
2. Add revenue and cost budget items.
3. Margin, margin percentage and status are computed automatically.
