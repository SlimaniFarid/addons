AI Invoice Scanner

Automate invoice and expense entry using AI vision models (Mistral, Gemini, Claude).

Upload PDF or image attachments and let AI extract vendor details, dates, amounts, line items, and taxes. Create vendor bills or HR expenses with one click.

Key Features

  • Multi-Provider Support — Mistral Pixtral, Google Gemini Pro Vision, Anthropic Claude 3
  • Smart Extraction — Vendor name, VAT, address, invoice number, dates, currency, totals, line items
  • Confidence Scoring — AI returns confidence level for each extraction
  • One-Click Bill Creation — Creates vendor bill in Accounting with extracted lines
  • Expense Integration — Creates HR expense records for employee reimbursements
  • Attachment Based — Works with any ir.attachment (email, upload, scanner)
  • Batch Processing Ready — Process multiple invoices via server actions

Supported Formats

  • PDF (single/multi-page)
  • Images: PNG, JPEG, WEBP, TIFF

Workflow

  1. Configure AI Provider with your API key (Mistral, Gemini, or Claude)
  2. Upload invoice attachment to an OCR Request (or use the "Scan Invoice" button on bills/expenses)
  3. Click "Process with AI" — extraction runs in seconds
  4. Review extracted data and confidence score
  5. Check "Create Vendor Bill" and/or "Create Expense" then process
  6. Generated records are linked for traceability

API Requirements

You need your own API keys from Mistral AI, Google AI Studio, or Anthropic Console. The module makes direct HTTPS calls — no data passes through our servers.

Compatibility

Odoo 18.0 and 19.0. Requires Accounting (account) and/or HR Expense (hr_expense) modules.
