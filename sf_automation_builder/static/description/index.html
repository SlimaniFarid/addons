Visual No-Code Automation Builder

Zapier-like visual builder for Odoo + external APIs

Key Features

  • Visual Canvas — Drag-drop nodes (React Flow based)
  • Triggers — Record CRUD, field change, cron, webhook, email, API
  • Actions — ORM CRUD, HTTP, email, Python, AI, webhook
  • Logic — If/else, loops, delays, formatters, code snippets
  • Variables — JSON path, Jinja2 templates between nodes
  • Built-in Connectors — Odoo, HTTP/REST, Email, AI, Webhooks, S3
  • Governance — Versioning, execution logs, rate limits, RBAC
  • Async Execution — queue_job or cron, test runs
  • Import/Export — JSON for backup/sharing

Compatibility

Odoo 18.0 and 19.0. Check module dependencies for required apps.
