User Manual

Step-by-step guide

Everything you need to get started.

1
Install the module

Copy sf_iatf_quality_suite to your addons path, restart Odoo, then go to Apps and click Install.

2
Assign user roles

Give your team the right access: IATF Quality User (operators), Engineer, Manager or PPAP Approver. Multi-company isolation is automatic.

3
Create your first FMEA

Click New in the FMEA menu. Choose DFMEA or PFMEA, add failure modes and rate S/O/D — the RPN calculates itself with color-coded risk classes.

4
Generate the Control Plan

From the PFMEA click Generate from PFMEA, set the RPN threshold, then Activate — quality points are created for the shop floor automatically.

FAQ

Common questions

Everything you need to know before installing.

Does this module work with Community edition?
Yes. It works on both Odoo Community and Enterprise editions.
Does it replace the ISO 9001 QMS module?
No — they are complementary. The QMS covers general ISO 9001 requirements (documents, NC/CAPA, audits, training); this toolkit adds the automotive-specific AIAG-VDA toolchain (FMEA, Control Plan, APQP, PPAP, MSA, SPC) required by IATF 16949. Many customers use both.
Can I use it on Odoo Online (SaaS)?
No. Odoo Online blocks third-party modules containing Python code. This module requires Odoo.sh, on-premise or Docker hosting — standard for automotive implementations.
Which AIAG standards are covered?
AIAG FMEA 4th Edition / AIAG-VDA (2019), APQP 3rd Edition, PPAP 4th Edition, MSA 4th Edition and SPC 2nd Edition, mapped to IATF 16949:2016 clauses 8.2.3.1, 8.3, 8.5.1, 8.5.6 and 9.1.1.
