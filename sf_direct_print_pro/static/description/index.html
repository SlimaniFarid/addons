Direct Print PRO

Print reports, labels, and documents directly to your printer — no PDF download required.

Send ZPL labels to thermal printers, PDFs to office printers, or raw text to receipt printers via TCP/IP, USB, Bluetooth, or PrintNode cloud.

Key Features

  • Network TCP/IP Printing — Direct raw socket connection to LAN/Wi-Fi printers (port 9100)
  • ZPL Label Support — Print shipping labels, barcodes, product labels to Zebra/thermal printers
  • PDF Printing — Via PrintNode cloud service for remote/office printers
  • Automated Printing — Auto-print on business events (picking validated, invoice posted, order confirmed)
  • Print Profiles — Map reports to printers with format, copies, and trigger rules
  • Job Queue & Retry — Failed jobs can be retried with full error logging
  • Multi-Printer — Manage multiple printers with different capabilities

Supported Printers

  • Zebra (ZPL), TSC, Datamax, Honeywell thermal label printers
  • Epson, Star, Bixolon POS receipt printers (ESC/POS)
  • Standard office printers via PrintNode (HP, Brother, Canon, etc.)
  • Bluetooth mobile printers (via OS print service)

Automation Examples

  • Print shipping label when delivery order is validated
  • Print barcode labels when products are received
  • Print invoice copy when invoice is posted
  • Print picking list when transfer is confirmed

Setup

  1. Add printer with IP address and port (default 9100)
  2. Test connection
  3. Create print profile linking a report to the printer
  4. Enable auto-print with trigger (model, field, value)
  5. Or manually print from the Print Jobs menu

Compatibility

Odoo 18.0 and 19.0. Works on any Odoo server with network access to printers. PrintNode requires internet.
