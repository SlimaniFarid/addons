AI Document Intelligence Hub

Classify, extract & route documents with AI

Key Features

  • Multi-Provider AI — Mistral, Gemini, Claude, OpenAI (BYOK)
  • Classification — Invoice, contract, CV, claim, PO, expense, other
  • Structured Extraction — Vendor, amounts, dates, parties, clauses, skills
  • Auto-Routing — Invoices→AP, contracts→Legal, CVs→HR, claims→Support
  • Human-in-the-Loop — Review queue with confidence thresholds
  • Learning Loop — Corrections retrain classification/extraction
  • Batch Processing — Email, scanner, portal upload
  • Audit Log — Full traceability

Compatibility

Odoo 18.0 and 19.0. Check module dependencies for required apps.
