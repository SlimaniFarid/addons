Membership & Associations

Complete membership management for associations, NGOs and clubs on Odoo 19.

The native membership module was removed in Odoo 18.3/19. This module provides a modern, standalone replacement with full features for member directories, subscription plans, recurring payments, automatic renewals, and donation tracking.

Key Features

  • Flexible Plans — Create individual, family, corporate, student plans with custom fees, durations, trial periods
  • Member Directory — Searchable member database linked to contacts with custom member codes
  • Subscription Lifecycle — Draft → Pending → Trial → Active → Expired/Cancelled with full state tracking
  • Automatic Renewals — Configurable auto-renewal with renewal history and count
  • Payment Tracking — Multiple payment methods, invoice generation, payment status workflow
  • Expiration Management — Daily cron checks for expiring/expired subscriptions with automatic status updates
  • Reports — Expiring soon, pending payments, member statistics
  • Website Ready — Compatible with Odoo Website for public member directory and online signups

Workflow

  1. Create membership plans (Individual, Family, Student, Corporate)
  2. Add members (creates linked contact automatically)
  3. Start subscription — generates draft invoice if needed
  4. Record payment — activates subscription automatically
  5. Auto-renewal cron creates new subscription period
  6. Track expirations and pending payments via reports

Compatibility

Works on Odoo 18.0 and 19.0. No dependency on the removed native membership module. Integrates with Sales, Invoicing, Website, and Mail.

Migration from Old Membership

Import existing members as contacts, create matching member records, then create subscriptions with historical start/end dates.
