Sales Auto Workflow

Automate sales order processing with configurable rules.

Reduce manual steps in your order-to-cash cycle. Define rules that automatically confirm orders, create deliveries, validate pickings, generate invoices, and send confirmation emails based on payment method, customer, amount, or any combination of conditions.

Key Features

  • Flexible Conditions — Payment method, order type, customer, tags, warehouse, amount range, salesperson, team, country
  • Match Logic — All conditions (AND) or any condition (OR)
  • Ordered Execution — Rules run in sequence priority
  • Full Automation — Confirm → Deliver → Validate → Invoice → Post → Email
  • Execution Logs — Track every rule application with success/error status
  • Per-Order Tracking — Prevent duplicate rule application on same order
  • Email Templates — Send custom confirmations on trigger

Example Rules

  • Cash on Delivery — Auto confirm, create delivery, validate, invoice, post
  • Online Payment — Auto confirm and create invoice immediately
  • Large Orders (>€10k) — Require manual approval (no auto rule)
  • Wholesale Customers — Auto create delivery but hold invoice for review

Workflow

  1. Create Auto Workflow Rules with conditions and actions
  2. Set sequence priority (lower runs first)
  3. Rules evaluate automatically when order is confirmed
  4. Matching rules execute their actions in order
  5. Check logs for execution history

Compatibility

Odoo 18.0 and 19.0. Works with Sale, Inventory, and Accounting modules. Compatible with native sale.order.type and payment methods.
