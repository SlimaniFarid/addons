Employee Loans &amp; Advances Manager
====================================

Manage employee loans and salary advances with approval
workflows and automatic repayment schedules.

Features
--------
* Loan and advance requests with approval workflow
* Automatic monthly repayment schedule
* Interest rate support
* Balance and paid amount tracking
* Late payment detection
* Per-company advance ceiling
* Loan schedule reporting

Requirements
------------
* Odoo 18.0 / 19.0 with the Employees (hr) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "Employee Loans &amp; Advances Manager".

Configuration
-------------
* In *Company Settings*, optionally set the *Max Advance per
  Employee* to enforce an outstanding ceiling.
* Grant the *Employee Loans User* or *Employee Loans Manager*
  groups to relevant users.

Usage
-----
1. Go to *Employees &gt; Employee Loans &gt; Loans*.
2. Create a loan for an employee with amount, duration and rate.
3. Submit the request, a manager approves it, then activate it.
4. The repayment schedule is generated automatically.
5. Record payments on each line; the balance updates live.

Permissions
-----------
* Employee Loans User: create and manage loan records.
* Employee Loans Manager: approve, activate, close and delete.
