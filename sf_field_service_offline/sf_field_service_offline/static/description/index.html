Field Service Offline-First Mobile

True offline-first mobile app for field technicians

Key Features

  • SQLite Local DB — Full work order management offline
  • Background Sync — Conflict resolution with vector clocks
  • GPS, Barcode, Photos — All captured offline
  • Equipment History — Cached locally for instant access
  • Auto-Sync — Wi-Fi preferred, cellular fallback
  • Admin Dashboard — Sync status, conflicts, pending per technician
  • Security — Encrypted storage, token auth, remote wipe
  • API Spec Included — Build Capacitor/Flutter app

Compatibility

Odoo 18.0 and 19.0. Check module dependencies for required apps.
