Events & Conferences Management

Event management for organizers, event project managers and ticketing teams.

Features

  • Events with dates, locations, capacities and budgets.
  • Sessions with speakers, rooms and schedules.
  • Registrations and ticketing with ticket types and capacity control.
  • Badge check-in with timestamps.
  • Budget and revenue tracking per event.
  • Daily reminder cron activities for upcoming events and negative balances.
  • Multi-company support with manager-only reserved actions.
  • PDF reports: event program, registration confirmation, budget and attendance.

Workflows

  • Event: Draft, Confirmed, In Progress, Done, Cancelled.
  • Registration: Draft, Confirmed, Checked In, Done, Cancelled.
  • Session: Draft, Confirmed, Done.
