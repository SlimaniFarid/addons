Service Contracts &amp; SLA Engine
================================

Manage service contracts with SLA tiers, breach tracking and recurring
billing in Odoo.

Features
--------
* Contracts with start/end dates and recurring billing
* SLA tiers: bronze, silver, gold with response targets
* SLA breach tracking on service events
* Contract status workflow: draft, active, expired, cancelled
* Automatic breach escalation

Requirements
------------
* Odoo 18.0 / 19.0 with Sales (sale) and Accounting (account).

Installation
------------
* Copy the module folder into your addons path.
* Install "Service Contracts &amp; SLA Engine".

Usage
-----
1. Define SLA tiers under *Sales &gt; Service Contracts &gt; SLA Tiers*.
2. Create a contract with a customer, dates and an SLA tier.
3. Add SLA events to the contract; breaches are computed automatically
   against the tier response and resolution targets.
