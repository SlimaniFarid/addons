Retail Franchise Network Management

Manage a franchise network: contracts, declared sales and automatic royalty invoicing.

Features

  • Franchise contracts with territory and royalty conditions.
  • Periodic sales declarations with automatic royalty calculation.
  • Royalty invoicing and payment tracking.
  • Daily reminders for invoicing and unpaid invoices.
  • Multi-company support.

Workflows

  • Contract: Draft, Active, Suspended, Terminated.
  • Declaration: Draft, Confirmed, Invoiced, Paid, Cancelled.
