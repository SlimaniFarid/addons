Dock & Shipment Appointment Scheduling

Truck appointment scheduling with time windows for warehouses and 3PL providers.

Features

  • Dock registry (receiving / shipping / both).
  • Appointments with configurable time windows.
  • Overlap detection on the same dock.
  • Workflow: Scheduled, Arrived, Docked, Completed, No-Show, Cancelled.
  • Automatic delay and dock-duration computation.
  • Daily no-show detection cron with follow-up activities.
  • Dock appointment schedule PDF.
  • Multi-company support.
