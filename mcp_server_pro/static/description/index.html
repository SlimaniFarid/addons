MCP Server PRO

Connect AI assistants to your Odoo instance securely.

This module implements a Model Context Protocol (MCP) compatible endpoint that allows AI assistants like Claude, ChatGPT, or custom agents to query your Odoo data in real-time through a standardized API.

Key Features

  • Secure JSON-RPC 2.0 endpoint with API key authentication
  • Configurable model exposure (partners, products, sales, inventory, accounting)
  • Rate limiting per server instance
  • Full request/response logging with audit trail
  • Multiple token management with rotation and expiration
  • Compatible with MCP clients and custom AI integrations

How it Works

  1. Create an MCP Server record with a unique code
  2. Configure which models the AI can access
  3. Generate API tokens for your AI assistant
  4. Connect your AI client to /mcp//json with Bearer token
  5. Call tools: search_, read_

    6. Supported Tools

    • search_res.partner - Find partners by name, email, phone
    • search_product.product - Search products with stock info
    • search_sale.order - Query sales orders
    • search_account.move - Access invoices and bills
    • search_stock.quant - Check real-time inventory

    Security

    All requests require a valid API key. Models are explicitly whitelisted. Request logging provides full auditability. Rate limits prevent abuse.

    Compatibility

    Works with any MCP-compatible client. Tested with Claude Desktop, custom Python/JS integrations.
