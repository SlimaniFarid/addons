Professional Services Automation
=================================

Run a professional services business in Odoo.

Features
--------
* Client engagements with budgets
* Resource pool with roles and rates
* Assignments with allocation and utilization
* Time entries linked to engagements
* Progress and utilization reporting

Requirements
------------
* Odoo 18.0 / 19.0 with Sales (sale) and Project (project) modules.

Installation
------------
* Copy the module folder into your addons path.
* Install "Professional Services Automation".

Usage
-----
1. Create client partners and resources under *PSA &gt; Resources*.
2. Create an engagement under *PSA &gt; Engagements* and link a client.
3. Assign resources under *PSA &gt; Assignments*.
4. Log time under *PSA &gt; Time Entries*; utilization and progress are
   computed automatically.
