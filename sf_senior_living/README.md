# Senior Living & Retirement Community Management

## Objectif
Complete management for senior residences, EHPAD, retirement communities

## Fonctionnalités
Unified resident dossier (admin, medical, social), care plans, medical coordination, activities, catering, multi-component billing, family portal, regulatory compliance.

## Installation
Standard Odoo module installation.

## Configuration
Configure via Settings > Senior Living & Retirement Community Management.

## Utilisation
Refer to the user guide.

## Permissions
- User: group_sf_senior_living_user
- Manager: group_sf_senior_living_manager

## Dépendances
base, mail, contacts, account

## Compatibilité
Odoo 18 / Odoo 19
