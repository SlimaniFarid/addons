User Guide

Step-by-step usage guide

1
Install & Set Up
Copy the module to your Odoo addons folder, restart and install from the Apps menu. Assign the User or Manager security group to your team.
2
Create Your First Record
Open the module from the main menu and click New. Fill in the key information - the form guides you with required fields clearly marked.
3
Follow the Workflow
Use the action buttons in the header to move records through their lifecycle. Each transition is logged in the chatter.
4
Analyze & Report
Switch between list, kanban and pivot views to analyze your data. Group by any field, filter by date or status.
5
Collaborate

FAQ

Common questions

Does this work with Odoo Community edition?
Yes. This module works on both Odoo Community and Enterprise editions with identical features.
Is it multi-company ready?
Yes. Record rules ensure each company only sees its own data.
Can I use it on Odoo Online (SaaS)?
No. This module contains Python code and requires Odoo.sh, on-premise or Docker hosting.
Is it translatable?
Yes. All user-facing strings are in English and can be translated via Odoo i18n tools.
Can I customize it?
Yes. Standard Odoo development conventions are used throughout.
