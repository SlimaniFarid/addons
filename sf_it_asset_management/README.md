IT Asset &amp; License Manager
============================

Centralize your IT fleet: equipment, software licenses,
assignments, warranties and maintenance.

Features
--------
* Equipment inventory with categories and states
* Employee assignment tracking
* Software license management with seats and expiration
* Warranty and license expiry alerts
* Valued inventory reporting
* License compliance reporting

Requirements
------------
* Odoo 18.0 / 19.0 with the Employees (hr) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "IT Asset &amp; License Manager".

Usage
-----
1. Go to *IT Assets &gt; Equipment*.
2. Create equipment with category, vendor, warranty and value.
3. Assign equipment to employees (Mark In Stock, then Assign).
4. Manage licenses under *IT Assets &gt; Licenses*.
5. The expiration cron flags expiring warranties and licenses.

Permissions
-----------
* IT Asset User: manage equipment and assignments.
* IT Asset Manager: full control including retire and licenses.
