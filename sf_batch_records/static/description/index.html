How to Use This Module

1
Install
Copy sf_batch_records to your addons path, restart Odoo, install from Apps.
2
Set up security
Assign User or Manager group to team members under Settings > Users.
3
Create records
Open the module from the main menu. Click New to create your first record.
4
Follow the workflow
Use the header buttons to move records through their status pipeline.
5
Search and analyze
Use list view to search and filter. Use kanban for visual overview.
6
Get help
Contact tech5262@gmail.com. We respond within 24 hours.

Security & Access Control

User Group: Create, read, edit records. No delete.

Manager Group: Full access including delete and configuration.

FAQ

Does this work with Odoo Community?
Yes. Both Community and Enterprise editions.
Is it multi-company ready?
Yes. Record rules ensure data isolation per company.
Can I use it on Odoo Online?
No. Requires Odoo.sh, on-premise or Docker hosting.
Is it translatable?
Yes. All strings translatable via Odoo i18n tools.
