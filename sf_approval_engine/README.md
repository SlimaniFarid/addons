# Approval Engine

Reusable multi-step approval workflows for any document.

## Features

- Approval templates with multiple ordered steps
- Automatic assignment: specific user, manager of requester, or group
- Per-step amount thresholds and always-required flags
- Silent auto-approve when steps are not applicable
- Rejection with reason, reset to draft and re-submit
- Full audit trail of approvals per request
- To-approve inbox for each user
- Can be attached to native documents (purchase orders, expenses, leave, ...)

## Installation

Install the module from Apps. Open the **Approvals** app.

## Usage

1. **Approvals > Approval Templates**: create a template, pick the target
   model and define ordered steps with approvers and thresholds.
2. **Approvals > Approval Requests**: requests are created from your
   documents. Submit, approve, reject, and track history.
