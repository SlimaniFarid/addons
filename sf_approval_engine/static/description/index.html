How it works

  1. Create an approval template and pick the target model.
  2. Add steps: name, approver (specific/manager/group), amount range.
  3. The mixin creates an approval request when a matching document is created.
  4. Approvers approve or reject; the flow advances automatically.
  5. Track the full history from the request form.

Frequently asked questions

Which models can it approve? Any model you attach the provided mixin to — out of the box the engine is model-agnostic.

What happens when a step is not applicable? It is skipped automatically (silent auto-approve).

Can a request be resubmitted after rejection? Yes — reset to draft, edit and submit again.
