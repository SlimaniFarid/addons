User Manual

Step-by-step guide

Everything you need to get started.

1
Install the module

Copy sf_bank_stmt_import_pro to your addons path, restart Odoo, then go to Apps and click Install.

2
Create templates for your banks

Bank Import Pro > Templates > New. For CSV: map columns (0-based), pick delimiter, date format and separators. MT940/CAMT/OFX/QIF need no template mapping.

3
Create your first import run

Import Runs > New: choose the bank journal and template, upload the statement file, click Parse File.

4
Review and import

Check the preview grid (duplicates in red), then click Import Lines. The bank statement opens, ready to reconcile.

FAQ

Common questions

Everything you need to know before installing.

My bank only offers CSV exports. Will it work?
Yes. Create one template mapping your bank's columns, delimiter and date format — then every future export from that bank imports in three clicks.
What happens if I import the same file twice?
Every line gets a SHA-256 fingerprint (journal + date + amount + reference) compared against your import history. Duplicates are flagged in red and skipped — no double bookings. A force-import option exists for edge cases.
Does it replace the bank synchronization (bank feed)?
No — it complements it. For banks without a supported live feed (regional banks, MT940 exports, CAMT downloads from e-banking portals), this module imports the same data manually in seconds.
Are foreign currency statements supported?
Yes. Lines in another currency than the journal keep their currency on the statement line when that currency exists in Odoo, so amounts and rates stay correct.
