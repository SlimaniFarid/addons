PDF Report Builder

Design professional PDF reports without writing code.

Replace Odoo's standard QWeb reports with custom templates built using a visual block editor. Add logos, text, dynamic fields, tables, signatures, and more. Assign templates per document type and company.

Key Features

  • Visual Block Editor — Drag-and-drop blocks: Logo, Text, Field, Table, Signature, Image, Separator, Spacer, HTML, Page Break
  • Dynamic Fields — Insert any model field with formatting (currency, date, percentage, float)
  • Line Tables — Auto-generate tables for order lines, invoice lines, move lines with custom columns
  • Signature Support — Insert signature images from binary fields
  • Conditional Blocks — Show/hide blocks based on record values (Python expressions)
  • Per-Company Templates — Different layouts per company
  • Override Standard Reports — Replace built-in reports (invoices, quotes, pickings) with custom templates
  • Page Control — Margins, orientation, headers, footers, page numbers
  • Live Preview — Generate PDF preview with sample data instantly

Workflow

  1. Create a Report Template for a model (e.g., account.move for invoices)
  2. Add blocks in order: Logo → Header fields → Line Table → Totals → Signature
  3. Configure field formats and table columns
  4. Set conditional visibility (e.g., show signature only if state=posted)
  5. Create Assignment to replace standard report action
  6. Click "Preview PDF" to test with sample data

Compatibility

Odoo 18.0 and 19.0. Works with Sale, Purchase, Inventory, Accounting. Generates standard QWeb-PDF reports.
