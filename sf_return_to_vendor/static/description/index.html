FAQ

Common questions

Everything you need to know before installing.

Does it create the vendor credit note?
It tracks the debit note reference; credit note creation follows your purchase return process.
Are lots preserved on return?
Yes - the return picking carries lot/serial numbers.
Can I scrap on site?
Yes - disposition Scrap On Site keeps the goods out of the return picking.
