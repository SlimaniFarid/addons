AI Demand Forecasting

ML-powered demand forecasting for inventory optimization

Key Features

  • Automated ML Training — Gradient Boosting / Random Forest on historical data
  • Per-Warehouse Forecasts — Product-level predictions with confidence intervals
  • Seasonality & Promotions — Automatic detection of seasonal patterns and promo lifts
  • Weather & Holidays — Optional external data integration
  • Replenishment Recommendations — Service-level driven orderpoint suggestions
  • Model Performance Dashboard — MAE, MAPE, bias tracking per model
  • Auto-Retraining — Scheduled incremental retraining via cron
  • Native Integration — Feeds Odoo's native procurement (orderpoint) system

Compatibility

Odoo 18.0 and 19.0. Check module dependencies for required apps.
