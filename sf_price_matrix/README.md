B2B Price &amp; Discount Matrix
==============================

Tiered B2B pricing and discount rules in Odoo.

Features
--------
* Customer categories with discount levels
* Tiered pricing by quantity
* Automatic discount application on sale orders
* Override rules per customer
* Margin safety checks (max discount)

Requirements
------------
* Odoo 18.0 / 19.0 with Sales (sale) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "B2B Price &amp; Discount Matrix".

Usage
-----
1. Define customer categories under *Sales &gt; Price Matrix &gt; Customer
   Categories*.
2. Create discount tiers under *Discount Tiers*.
3. Link products to categories with their tiers under *Price Rules*.
4. Assign a category to a partner; sale orders for that partner get the
   matching discount automatically.
