# Marketplace Hub

Run your own multi-vendor marketplace on top of Odoo.

## Features

- Marketplace records per channel (web store, Amazon, eBay, local)
- Vendors with commission rates and payout accounts
- Product listings managed per marketplace vendor
- Orders funneled from any channel into a single hub
- Commission computed automatically on sold amounts
- Payout batches with draft → approved → paid workflow
- Dashboards: GMV, commissions, vendor performance
- Multi-currency support and per-company isolation

## Installation

Install the module from Apps. Open **Sales > Marketplace**.

## Usage

1. Create a marketplace (web store, Amazon, eBay...).
2. Add vendors with their commission rate.
3. Create listings for the products each vendor sells.
4. Track sold quantities; commissions are computed automatically.
5. Generate payouts and approve/pay them.
