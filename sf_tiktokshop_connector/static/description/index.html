TikTok Shop Connector

Synchronize products, inventory, orders, and returns between Odoo and TikTok Shop.

TikTok Shop is one of the fastest-growing social commerce platforms. This connector uses the official TikTok Shop Open API to keep your Odoo catalog and orders in sync.

Key Features

  • Bidirectional Sync — Pull products/orders from TikTok, push inventory updates
  • Multi-Shop Support — Connect multiple TikTok Shop accounts
  • Product Mapping — Link TikTok products to Odoo products (auto-create or manual)
  • Order Import — Import orders with buyer details, shipping info, line items
  • Inventory Sync — Push Odoo stock quantities to TikTok Shop
  • Automated Cron — Schedule periodic sync for products, inventory, orders
  • Sync Logs — Full audit trail with error details
  • Webhook Ready — Handle real-time notifications (order created, status changed)

Supported Regions

US, UK, Indonesia, Malaysia, Philippines, Singapore, Thailand, Vietnam, Saudi Arabia

Operations

OperationDirectionDescription
ProductsPullImport product catalog with images, SKUs, categories
InventoryPushUpdate stock quantities from Odoo to TikTok
OrdersPullImport orders with buyer, shipping, line items
ReturnsPullImport return/refund requests

Setup

  1. Register a TikTok Shop Developer App at https://partner.tiktokshop.com
  2. Get App Key and App Secret
  3. Authorize the app for your shop to get Access Token
  4. Create a TikTok Shop record in Odoo with credentials
  5. Click "Test Connection" then "Sync Products"
  6. Configure cron jobs for automated sync

Compatibility

Odoo 18.0 and 19.0. Requires Sales, Inventory, and Accounting modules.
