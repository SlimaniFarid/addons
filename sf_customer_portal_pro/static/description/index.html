Customer Self-Service Portal Pro

B2B/B2C portal: invoices, payments, subscriptions, tickets

Key Features

  • Secure Login — OAuth2, SAML, magic link, email/password
  • Dashboard — Invoices, orders, subscriptions, tickets, usage
  • Payments — Stripe, Adyen, PayPal, bank (auto-reconcile)
  • Subscriptions — Upgrade/downgrade/cancel, usage meters
  • Returns/RMA — Initiate with label printing
  • Support Tickets — Create, track, chat, knowledge base
  • Document Center — Contracts, certificates, compliance
  • White-Label — Custom domain, CSS, email templates
  • Headless API — For custom React/Vue/Flutter frontends

Compatibility

Odoo 18.0 and 19.0. Check module dependencies for required apps.
