User Manual

Step-by-step guide

Everything you need to get started.

1
Install the module

Copy sf_safety_stock to your addons path, restart Odoo, then go to Apps and click Install.

2
Assign user access

Go to Settings → Users, open a user and add the Safety Stock Optimizer / User or / Manager group under the extra rights.

3
Open the application

Find Safety Stock in your Odoo main menu. Everything is organised under this single entry point.

4
Create your first record

Click New on the Safety Stock Rule list view. Fill in the required fields and save. Chatter and activities are available on every record.
