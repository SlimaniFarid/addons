Andon & Alert System
=======================

Real-time visual management for manufacturing shop floor.

Features
--------
* Andon calls: quality, maintenance, material, safety, process, other
* Four severity levels with priority computation
* Multi-level escalation rules with delays
* Visual boards (Kanban, tower light integration ready)
* Response tracking with timestamps
* MTTR and response time analytics
* Integration with MES work orders

Requirements
------------
* Odoo 18.0 / 19.0 with Manufacturing (mrp), Maintenance (maintenance)

Installation
------------
* Copy the module folder into your addons path.
* Install "Andon & Alert System".

Usage
-----
1. Configure stations under *Manufacturing > Andon System > Stations*.
2. Set up escalation rules under *Escalation Rules*.
3. Operators create calls from the dashboard or station interface.
4. Responders acknowledge, work, and resolve calls.
5. Track KPIs on the Dashboard.
