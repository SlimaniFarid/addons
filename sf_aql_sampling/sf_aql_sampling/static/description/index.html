Acceptance Sampling & AQL Inspection Plans

Statistical acceptance sampling for quality departments.

Features

  • Sampling plans with lot size range, sample size and accept/reject numbers.
  • Lot inspections with automatic plan selection.
  • Defect recording by severity with weighted scoring.
  • Automatic accept/reject decisions.
  • Release or rejection of inspected lots.
  • AQL inspection report PDF.
  • Multi-company support.

Workflows

  • Inspection: Draft, In Progress, Completed, Released, Rejected, Cancelled.
  • Decision: Accepted or Rejected computed from defects.
  • Release requires an accepted decision and manager rights.
