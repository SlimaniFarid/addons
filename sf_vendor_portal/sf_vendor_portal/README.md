# Vendor Portal & e-Procurement

Let your suppliers collaborate online instead of exchanging emails.

## Features

- Secure self-service portal for each vendor (portal access)
- Vendors see their quotations (RFQs), confirmed orders and invoices
- Accept, decline or propose a counter-offer from the portal
- Automatic welcome message when the portal is enabled
- Vendor dashboard with totals and response status
- Optional auto-creation of portal users for new vendors
- Optional email notification on new RFQs

## Installation

Install the module from Apps. Open **Purchasing > Vendor Portal**.

## Usage

1. Open a supplier contact and enable **Vendor Portal User**.
2. Press **Create Portal User** to send the welcome message.
3. The vendor signs in and responds to your RFQs online.
4. Track every response in the purchase order chatter.
