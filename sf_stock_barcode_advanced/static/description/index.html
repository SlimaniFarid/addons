Barcode & Warehouse

Advanced barcode scanning for receipts, deliveries, and inventory adjustments.

Native barcode scanning in Odoo is limited. This module brings a mobile-friendly scanning wizard with support for EAN13, UPC, QR, Code128, GS1, and custom formats. Automatically parse GS1 codes, create lots/serials/packages on the fly, and log every scan.

Key Features

  • Multi-Format Support — EAN13, UPC-A/E, Code128, QR, GS1 (AI 01, 10, 21, 30, etc.)
  • Smart Parsing — Auto-detect barcode type and extract GTIN, lot, serial, quantity
  • GS1 Application Identifiers — Parse (01) GTIN, (10) Lot, (21) Serial, (30) Qty, (15) Best Before, (17) Expiry
  • Auto-Create Entities — Automatically create lots, serial numbers, packages when scanning unknown codes
  • Mobile-Friendly Wizard — Full-screen scan form works on tablets and phones
  • Picking Integration — Add move lines directly from scan results
  • Scan Logging — Complete audit trail with user, time, parsed data, success/error
  • Configurable Patterns — Custom regex per company for your barcode formats

Supported Operations

  • Receipts (incoming shipments)
  • Deliveries (outgoing shipments)
  • Internal Transfers
  • Inventory Adjustments

Workflow

  1. Open "Scan Barcode" from menu or add button to picking form
  2. Select picking and configuration
  3. Scan barcode with device camera or handheld scanner
  4. System auto-detects type and parses data
  5. Review and confirm — move line added to picking
  6. Continue scanning or click Done

GS1 Example

Scan: (01)01234567890128(10)LOT123(30)50

  • Product: GTIN 01234567890128 → matched to product with that barcode
  • Lot: LOT123 → auto-created or linked
  • Quantity: 50 → pre-filled

Compatibility

Odoo 18.0 and 19.0. Works with standard Inventory (stock) and Product modules. Compatible with handheld Bluetooth scanners and mobile device cameras.
