Traceability &amp; Batch Recall
============================

Full batch and serial traceability in Odoo, including recall events and
affected customer tracking.

Features
--------
* Batch recall events with severity levels
* Affected customers computed from deliveries
* Full product movement history per lot
* Recall workflow: open, in progress, closed
* Batch quality status tracking
* Expiry dates and batch origins

Requirements
------------
* Odoo 18.0 / 19.0 with Inventory (stock) module.

Installation
------------
* Copy the module folder into your addons path.
* Install "Traceability &amp; Batch Recall".

Usage
-----
1. Under *Inventory &gt; Traceability &gt; Recalls*, create a recall for a
   batch and set its severity and reason.
2. Affected customers and movement counts are computed from done stock
   moves.
3. Open a batch to view its quality status, expiry date and movement
   history.
