Access Rights Manager

Granular permission control without developer mode.

Odoo's native access control requires developer mode and technical knowledge. This module provides a user-friendly interface to configure fine-grained permissions for any user group.

Key Features

  • Menu Control — Hide or show specific menus for selected groups
  • Field-Level Security — Make fields read-only, invisible, or required per group
  • Action/Report Restrictions — Deny or allow access to specific actions and reports
  • Export Control — Block or limit data exports per model and group
  • Multi-Company — Policies can be scoped to specific companies
  • Policy Management — Multiple policies with priority ordering
  • Audit Trail — Track policy changes via chatter
  • No Code Required — Configure entirely from the UI

Rule Types

  • Menu Rules — Hide navigation items from specific roles (e.g., hide Accounting from Sales team)
  • Field Rules — Make sensitive fields read-only for junior staff, invisible for external users
  • Action Rules — Restrict access to specific reports, wizards, or server actions
  • Export Rules — Prevent data exports for certain models or limit to specific fields

How It Works

  1. Create an Access Policy with a name and code
  2. Select target user groups (e.g., "Sales / User", "Accountant")
  3. Optionally limit to specific companies
  4. Add rules: Menu, Field, Action, or Export
  5. Click "Apply Policy" to activate
  6. Rules take effect immediately for users in target groups

Use Cases

  • Hide Accounting menu from non-finance users
  • Make "Cost Price" field invisible for sales team
  • Block "Export All" for customer data (GDPR)
  • Restrict "Delete" action on validated invoices
  • Multi-company: different permissions per entity

Compatibility

Odoo 18.0 and 19.0. Works alongside native ir.model.access and record rules.
