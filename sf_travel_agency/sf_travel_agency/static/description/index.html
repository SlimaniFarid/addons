SF Travel Agency

Manage travel packages, providers, reservations and provider costs with margin analysis for Odoo 18.

Features

  • Travel packages with destination, dates, price, capacity and providers.
  • Providers grouped by type: hotel, transport, activity, insurance, other.
  • Reservation workflow: draft, confirmed, paid, completed, cancelled.
  • Automatic cost, commission and margin computation.
  • Package capacity control.
  • Daily reminders for imminent departures and long-unpaid confirmed reservations.
  • Manager-only protections for prices, paid cancellations and provider archiving.
  • Multi-company support.
  • QWeb reports: Reservation Confirmation, Package Itinerary, Reservation Invoice, Margin Report.
